# Sổ lúa Pickleball – GitHub Pages

1. Tạo repository GitHub Public.
2. Tải toàn bộ nội dung trong thư mục này lên thư mục gốc của repository.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)` rồi bấm **Save**.
5. Mở địa chỉ `https://TEN-GITHUB.github.io/TEN-REPOSITORY/`.

Bản này có PWA, xuất ảnh độ phân giải cao 3x, PDF khổ ngang A4 với font tiếng Việt/cột tự xuống dòng, và chức năng gộp nhiều tên trong mục **Thống kê tất cả các đợt**.
